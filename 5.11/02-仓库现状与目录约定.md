# 仓库现状与目录约定

## 当前主要模块

| 模块 | 位置 | 定位 |
|---|---|---|
| 根 Rust CLI | `Cargo.toml`、`src/main.rs` | PDF/OCR/Document Intelligence 前处理工具 |
| TauriExam | `TauriExam/` | 本地考试客户端，未来可作为在线受控客户端 |
| SC-100 skill | `.github/skills/sc100-vision-md/` | SC-100 PDF 视觉读题与导入流程 |
| exam-question-gen skill | `.github/skills/exam-question-gen/` | AI 原创模拟题生成与导入流程 |
| PowerShell 脚本 | `continue-*.ps1`、`batch-add-interactions.ps1` | 当前流水线胶水 |
| 数据资产 | `output/`、`question-banks/` | 中间产物与最终题库产物 |

## 题库目录权威顺序

当前需要按这个顺序理解：

```text
question-banks/                              # 作者/构建阶段权威输出
%LOCALAPPDATA%/TauriExam/question-banks/     # Tauri 当前运行时副本
TauriExam/question-banks/                    # 开发种子/历史兼容副本
```

## 根目录 `question-banks/`

这是当前作者侧权威输出目录。

- AI/skill/importer 最终生成的 SQLite 应默认写这里。
- `SC-100.sqlite`、`AI-900.sqlite` 这类文件应以这里为准。
- 未来服务端导入或打包也应从这里取作者确认后的题库。

## `%LOCALAPPDATA%/TauriExam/question-banks/`

这是当前 TauriExam 普通运行时优先读取目录。

当前逻辑：

- 第一次运行时，如果这里没有题库，TauriExam 会从旧位置迁移/复制题库。
- 如果这里已经有任意题库文件，后续不会自动被根目录覆盖。
- 需要更新时，必须通过同步脚本或显式导入。

## `TauriExam/question-banks/`

这个目录当前只应视为：

- 开发副本。
- 打包种子。
- 历史兼容迁移来源。

不建议继续把它当权威数据源。

## `output/` 的定位

`output/` 大部分是中间产物，但其中有两类高价值源数据：

- `output/vision-md/`：视觉读题后的标准 Markdown。
- `output/exam-gen/`：AI 原创题 Markdown。

这些 Markdown 是可审计源数据，不应简单当缓存删除。

## 建议同步方向

```text
question-banks/*.sqlite  ->  %LOCALAPPDATA%/TauriExam/question-banks/*.sqlite
question-banks/*.sqlite  ->  TauriExam/question-banks/*.sqlite（仅开发需要）
```

不要从 `%LOCALAPPDATA%` 反向覆盖根目录权威题库，除非脚本显式要求。
