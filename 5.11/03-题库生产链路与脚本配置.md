# 题库生产链路与脚本配置

## 当前 SC-100 生产链路

```text
SC-100 PDF
  -> 渲染 PDF 页
  -> Copilot/视觉读取
  -> 标准 Markdown
  -> import_question_md_to_sqlite.py
  -> question-banks/SC-100.sqlite
  -> TauriExam 读取/验证/刷题
```

## 当前 AI 原创题生产链路

```text
考试代号，例如 AI-900
  -> exam-question-gen skill 生成 Markdown
  -> import_question_md_to_sqlite.py
  -> question-banks/AI-900.sqlite
  -> TauriExam 读取/验证/刷题
```

## 当前还依赖的东西

- VS Code/Copilot skill 负责题目视觉理解、生成和修复。
- Python 导入器负责 Markdown 到 SQLite。
- PowerShell 脚本负责批量续跑、检测缺失交互、增量导入和同步。

## Python 解析配置

已经新增统一入口：

```text

```

已接入：

```text

```

解析优先级：

| 配置项 | 用途 | 优先级 |
|---|---|---:|
| `-Python <path>` | 手动指定 Python | 1 |
| `DOCINTEL_PYTHON` | 仓库级/用户级 Python 路径 | 2 |
| `PYTHON` | 通用 Python 路径 | 3 |
| `python` / `python3` / `py -3` | 自动发现 | 4 |
| `-NoInstallPython` | 禁止自动安装 | 开关 |

默认行为：找不到 Python 时，脚本会尝试通过 `winget` 静默安装 Python 3.12。
